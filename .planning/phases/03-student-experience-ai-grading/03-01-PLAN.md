2. Add `openai_api_key: str = ""` and `openai_model: str = "gpt-4o-mini"` to Settings in config.py (with GRADEAI_ prefix).

3. Create backend/app/models/submission.py:
   - SubmissionBase(SQLModel): exam_id: int
   - Submission(SubmissionBase, table=True): id (PK), answers (JSON column — list of answer strings), grades (JSON column — list of grade dicts, nullable), total_score (int, nullable), is_final (bool, default=False), created_at (datetime)
   - Import this model in main.py so SQLModel registers it (like exam model).

4. Create backend/app/schemas/submission.py:
   - AnswerInput(SQLModel): question_index: int, answer: str
   - GradeResult(SQLModel): question_index: int, score: int, max_score: int, explanation: str
   - SubmissionCreate(SQLModel): exam_id: int, answers: list[AnswerInput]
   - GradingResponse(SQLModel): grades: list[GradeResult], total_score: int, max_score: int, is_final: bool
   - SubmissionRead(SQLModel): id: int, exam_id: int, answers: list[AnswerInput], grades: list[GradeResult] | None, total_score: int | None, is_final: bool, created_at: datetime

5. Create backend/app/services/grading.py:
   - `async def grade_answer(question_text: str, rubric: list[str], max_score: int, answer: str, api_key: str, model: str) -> GradeResult`
   - Use OpenAI chat completions API with a system prompt that instructs the AI to:
     - Grade the answer against the rubric points
     - Return a JSON object with "score" (0 to max_score) and "explanation" (2-3 sentences)
     - Be fair but rigorous, awarding partial credit
   - Parse the JSON response and return a GradeResult
   - Use `response_format={"type": "json_object"}` for reliable JSON output
   - `async def grade_submission(exam_questions: list, answers: list[AnswerInput], api_key: str, model: str) -> tuple[list[GradeResult], int]`
     - Grade each answer against its corresponding question
     - Return list of GradeResults and total_score
     - Use asyncio.gather to grade all answers concurrently
  </action>

  <action>
1. Create backend/app/routers/submissions.py with APIRouter(prefix="/api/submissions", tags=["submissions"]):

   - POST /preview — Preview grading (Try button):
     - Accepts SubmissionCreate body
     - Loads the exam by exam_id (404 if not found)
     - Calls grade_submission with exam questions and answers
     - Returns GradingResponse with is_final=False
     - Does NOT persist to database

   - POST / — Final submission (Submit button):
     - Accepts SubmissionCreate body
     - Loads the exam by exam_id (404 if not found)
     - Calls grade_submission with exam questions and answers
     - Creates Submission record with answers, grades, total_score, is_final=True
     - Returns GradingResponse with is_final=True

   - GET /{submission_id} — Get submission with grades:
     - Returns SubmissionRead
     - 404 if not found

   - Both grading endpoints are async (the grading service uses async OpenAI calls).
   - Use settings.openai_api_key and settings.openai_model from config.
   - Return 400 if openai_api_key is empty with message "OpenAI API key not configured".

2. Register the submissions router in main.py (import and include_router, same pattern as exams_router). Also add `import app.models.submission` at the top to register the model.

3. Make sure the grading endpoints handle OpenAI errors gracefully — catch exceptions and return 500 with error detail.
