Replace the current minimal README.md with a comprehensive version. Include these sections:

**Header:**
- Project name: GradeAI
- One-line description: LLM-powered system for evaluating subjective answers using rubrics and structured reasoning with explainable scoring.
- Brief feature list (3-4 bullets): AI grading with rubrics, instant feedback with Try/Submit flow, PDF export, auto-seeded demo exam

**Tech Stack:**
- Frontend: React 19, Vite, Tailwind CSS v4, shadcn/ui
- Backend: FastAPI, SQLModel, SQLite, OpenAI API
- Deployment: Vercel (frontend), Render (backend)

**Local Development:**
- Prerequisites: Python 3.11+, Node.js 18+, OpenAI API key
- Backend setup:
  ```
  cd backend
  pip install -r requirements.txt
  export GRADEAI_OPENAI_API_KEY=your-key-here
  uvicorn app.main:app --reload
  ```
- Frontend setup:
  ```
  cd frontend
  npm install
  npm run dev
  ```
- Note: Backend runs on http://localhost:8000, frontend on http://localhost:5173

**Deployment section:**

*Backend (Render):*
1. Create a Render account at render.com
2. Connect your GitHub repository
3. Render auto-detects `render.yaml` and creates the service
4. Set `GRADEAI_OPENAI_API_KEY` in Render environment variables
5. After frontend deploys, set `GRADEAI_CORS_ORIGINS` to `["https://your-app.vercel.app"]`
6. Note: Free tier has ~30s cold starts after 15min inactivity; SQLite data resets on each deploy (demo data auto-seeds)

*Frontend (Vercel):*
1. Create a Vercel account at vercel.com
2. Import your GitHub repository
3. Set root directory to `frontend`
4. Framework preset: Vite
5. Add environment variable: `VITE_API_URL` = your Render backend URL (e.g., `https://gradeai-api.onrender.com`)
6. Deploy

**Environment Variables table:**
| Variable | Where | Required | Description |
|----------|-------|----------|-------------|
| GRADEAI_OPENAI_API_KEY | Render | Yes | OpenAI API key for AI grading |
| GRADEAI_CORS_ORIGINS | Render | Yes | JSON array of allowed frontend origins |
| GRADEAI_DATABASE_URL | Render | No | SQLite URL (defaults to sqlite:///./data.db) |
| VITE_API_URL | Vercel | Yes | Backend API URL |

Keep the tone concise and practical. No marketing fluff.

<task type="checkpoint:human-action" gate="blocking">
  <name>Task 2: Deploy to Vercel and Render</name>
  <action>
Deploy the application to production. This requires human interaction with platform dashboards.

**Step 1: Deploy Backend to Render**
1. Go to https://dashboard.render.com
2. Click "New" -> "Web Service"
3. Connect your GitHub repo (GradeAI)
4. Render should auto-detect render.yaml — if not, manually set:
   - Root directory: `backend`
   - Build command: `pip install -r requirements.txt`
   - Start command: `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
5. Set environment variable: `GRADEAI_OPENAI_API_KEY` = your OpenAI key
6. Click "Create Web Service"
7. Wait for deploy to complete. Note the service URL (e.g., `https://gradeai-api.onrender.com`)
8. Test: visit `https://your-service.onrender.com/health` — should return `{"status":"ok"}`

**Step 2: Deploy Frontend to Vercel**
1. Go to https://vercel.com/new
2. Import your GitHub repo (GradeAI)
3. Set root directory to `frontend`
4. Framework preset should auto-detect as Vite
5. Add environment variable: `VITE_API_URL` = your Render URL from Step 1
6. Click "Deploy"
7. Note the Vercel URL (e.g., `https://gradeai.vercel.app`)

**Step 3: Update CORS on Render**
1. Go back to Render dashboard -> your service -> Environment
2. Add: `GRADEAI_CORS_ORIGINS` = `["https://your-app.vercel.app"]` (use your actual Vercel URL)
3. This triggers a redeploy

**Step 4: Verify**
1. Visit your Vercel URL
2. App should load with the demo exam
3. Try answering questions and clicking "Try" to test AI grading
