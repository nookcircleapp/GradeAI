  <action>
    From frontend/ directory:

    1. Install Tailwind CSS v4:
       ```
       npm install tailwindcss @tailwindcss/vite
       ```

    2. Update vite.config.ts to add tailwindcss() plugin (import from @tailwindcss/vite). Keep react() plugin too.

    3. Create src/styles/globals.css with `@import "tailwindcss";` at the top. Add CSS variables for shadcn/ui theme (will be auto-generated by shadcn init).

    4. Update src/main.tsx to import './styles/globals.css' instead of default CSS.

    5. Initialize shadcn/ui:
       ```
       npx shadcn@canary init
       ```
       Choose: New York style, Zinc base color, CSS variables: yes.
       This creates components.json and sets up the lib/utils.ts with cn() helper.

    6. Add essential components:
       ```
       npx shadcn@canary add button card
       ```

    7. Update App.tsx to import and render a shadcn Button and Card to prove the setup works. Show a simple card with "GradeAI" title and a styled button. Use responsive classes: container mx-auto, p-4, etc.

    Do NOT hand-roll class concatenation — use cn() utility from lib/utils.ts.
    Do NOT use tailwindcss-animate — shadcn canary uses tw-animate-css for Tailwind v4.
  </action>
  <verify>
    cd frontend && npm run dev -- --port 5173 &
    Wait 3 seconds. Open http://localhost:5173 — should show styled Card with Button (not unstyled HTML).
    npm run build should succeed with no errors.

    Verify src/components/ui/button.tsx and src/components/ui/card.tsx exist.
    Kill dev server after verification.
  </verify>
