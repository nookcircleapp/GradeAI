    2. Create `frontend/src/components/ErrorBoundary.tsx` — a class-based React Error Boundary:
       - Props: `{ children: ReactNode }`
       - State: `{ hasError: boolean; error: Error | null }`
       - `getDerivedStateFromError` sets hasError + error
       - `componentDidCatch` logs error + componentStack to console.error
       - Fallback UI: centered card with "Something went wrong" title, error message, and a "Try again" button that resets state
       - Use Tailwind classes for styling (min-h-screen, bg-background, flex items-center justify-center)
       - The "Try again" button should use the shadcn Button component for consistency

    3. Wrap `<App />` with `<ErrorBoundary>` in `frontend/src/main.tsx`:
       ```tsx
       import { ErrorBoundary } from './components/ErrorBoundary'
       // ...
       <StrictMode>
         <ErrorBoundary>
           <App />
         </ErrorBoundary>
       </StrictMode>
       ```

    4. Add `<Toaster />` from sonner to `frontend/src/App.tsx`:
       ```tsx
       import { Toaster } from '@/components/ui/sonner'
       // Inside return, after closing </main>:
       <Toaster />
       ```

    5. Add `print:hidden` to the `<header>` element in App.tsx:
       Change `<header className="border-b">` to `<header className="border-b print:hidden">`
